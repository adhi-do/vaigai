# vaigai — VAIGAI'S IKIGAI Interactive Gazette & Flipbook

*The Bimonthly Gazette of Vaigai College of Engineering (Vol. 01 • Issue 01, July–August 2026)*

## Overview
An interactive, high-end 3D flipbook publication emulating an editorial newspaper and academic broadsheet. Built with responsive dual reading modes (3D Flipbook & Gazette Editorial Reader), Web Audio page rustle sound synthesis, touch support for Android/iOS, and rich academic content including NPTEL IIT Madras toppers, faculty research, student oratory laurels, and department milestones.

## Features
- **Interactive 3D Flipbook**: Realistic page turning, corner curling, and dynamic aspect-ratio sizing inspired by Heyzine.
- **Gazette Scroll Reader (📰)**: Dual reading mode offering continuous article flow, full-text live search, and quick jumping.
- **Mobile & Android Optimized**: Proportional single-page view, fluid internal touch scrolling, and responsive docking.
- **Audio Synthesizer**: Web Audio API tactile paper rustling sound effects with mute toggle.
- **Theme Engine**: Newsprint, Ivory, Sepia, and Dark color palettes.
- **Offline & Self-Contained**: Powered by local `page-flip.browser.js` with zero runtime build dependencies.

## Quick Start
To view locally:
```bash
python3 -m http.server 8080
```
Open `http://localhost:8080` in your browser.
